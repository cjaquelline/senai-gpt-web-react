# SenaiGPT React 
1. Verificar se tenho a versão do Node v20 instalado (node --version (cmd)).
   ![image](https://github.com/user-attachments/assets/ac4e1a9b-22db-44c1-bd74-fbdfabb15700)
   
- Caso não esteja instalado, segue link: https://nodejs.org/en/download

3. Ao criar um novo projeto (repositor e clonar no meu compoutdor), devo entrar no CMD da pasta e adicionar o seguinte comando: npm create vite@latest senai-gpt-web-react -- --template react
     ![image](https://github.com/user-attachments/assets/a7fed764-3335-48d7-a62d-0d039eb17e5c)
4. cd Endereço da pasta gerada dentro da pasta de origem. (cmd)
5. code . (cmd)
6. Dentro do VSCode, abra o CMD e digite os seguintes comandos:
 
npm install
     ![image](https://github.com/user-attachments/assets/bba84aa1-301c-48f3-99ed-521ed92dfc4c)
npm run dev 
 ![image](https://github.com/user-attachments/assets/61fa9e29-0687-4084-acc9-3afb75c18efe)

Ao clicar no link e abrir a pagina web: ![image](https://github.com/user-attachments/assets/984871ba-5780-47b0-a653-3bda4dc43393)

7. Dentro do VsCode posso instalar o ESLint, ele aponta os erros e o que não está sendo usado.
